Repositori ini berisi **unduhan resmi dan catatan rilis** aplikasi KASKOW Remote untuk Windows.
Kode sumber aplikasi bersifat privat.

## Unduh

- **Versi terbaru:** halaman [Releases](https://github.com/appkaskow/kaskow-remote/releases/latest)
  atau langsung dari [kaskow.com/p/remote-desktop/](https://kaskow.com/p/remote-desktop/).
- Sistem: Windows 10 atau 11 (64-bit).
- Pemasangan tidak butuh hak admin. Aplikasi memperbarui dirinya sendiri setelah terpasang.

Setiap rilis mencantumkan SHA-256 file installer. Pastikan nilainya sama sebelum menjalankan file
yang Anda dapat dari tempat lain.

## Cara pakai singkat

1. Pasang KASKOW Remote di komputer yang ingin dibuka dari jauh.
2. Buka aplikasinya, catat **ID** (9 digit) dan **password akses**.
3. Dari komputer atau HP lain, buka [kaskow.com/remote.html](https://kaskow.com/remote.html)
   atau aplikasi KASKOW Remote, masukkan ID dan password, lalu klik **Hubungkan**.

Butuh akun KASKOW untuk menghubungkan ke komputer lain.

## Peringatan saat mengunduh

Karena aplikasinya masih baru, Chrome atau Windows SmartScreen kadang meminta konfirmasi:

- **Chrome:** buka daftar unduhan, pilih **Keep / Simpan**.
- **Windows:** pada jendela *Windows protected your PC*, klik **More info**, lalu **Run anyway**.

## Keamanan

- Komputer hanya bisa dibuka dengan ID **dan** password akses dari pemiliknya.
- Pemilik komputer selalu melihat siapa yang sedang terhubung dan bisa memutus kapan saja.
- Password akses bisa diganti dari aplikasi kapan pun.
- Semua koneksi ke server KASKOW memakai HTTPS.

Menemukan masalah keamanan? Kabari kami lewat [kaskow.com](https://kaskow.com).
