# Catatan rilis KASKOW Remote

## 3.0.3 — 2 Oktober 2026

- Pembaruan otomatis lebih cepat: aplikasi mengecek versi baru setiap 30 menit dan setiap kali tersambung ke server, tanpa perlu klik "cek pembaruan".
- Saat memasang pembaruan, jendela proses instalasi kini tampil, lalu aplikasi terbuka lagi dengan sendirinya.
- Title bar ikut berubah langsung saat tema gelap/terang diganti, termasuk di Windows 10. Tombol minimize, maximize, dan close terlihat jelas.
- Jendela remote langsung tampil gelap, tidak putih sesaat.
- Tombol layar penuh di jendela remote berfungsi.
- Bahasa jendela remote mengikuti bahasa aplikasi (English / Indonesia).
- Lebih ringan selama sesi: clipboard hanya dibaca saat isinya berubah.

## 3.0.2 — 2 Oktober 2026

- Perbaikan koneksi: aplikasi tetap tersambung ke kaskow.com (status tidak lagi "Disconnected").
- Installer baru bergaya KASKOW, tanpa pertanyaan mode instalasi.
- Tampilan aplikasi tersedia dalam English dan Bahasa Indonesia, dengan tombol ganti bahasa.
- Gambar layar lebih tajam, semua tombol keyboard berfungsi, dan salin-tempel file/folder antar komputer dengan Ctrl+C / Ctrl+V.
